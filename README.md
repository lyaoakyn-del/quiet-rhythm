# Квадрат дыхания

Адаптивное PWA-приложение с четырьмя режимами дыхания: ровный квадрат, неравный квадрат 4/2/2/2, длинный выдох 4/6 и циклический вздох. Темп можно настроить в поддерживаемых режимах; дыхание должно оставаться комфортным. Бодрящий эффект неравного квадрата не доказан.

В приложении есть светлая и тёмная темы, искристый след за маркером на тёмном фоне, статистика практик и необязательный трекер настроения. Без аккаунта история хранится локально. Для синхронизации между устройствами используется Firebase Authentication со входом по ссылке на почту и Firestore в `europe-north1` (Финляндия). При первом входе приложение создаёт аккаунт; локальная история объединяется с облачной.

Сайт размещается как статические файлы на GitHub Pages. Firebase выполняет роль backend для аккаунтов и истории; отдельный сервер приложения не нужен. Firebase Web SDK загружается с официального CDN. Firebase Web-конфигурация находится в `dist/firebase-config.js`; её API key предназначен для клиентского приложения, а доступ к данным ограничивают правила Firestore.

Публичная версия: <https://lyaoakyn-del.github.io/quiet-rhythm/>.

## Локальный запуск

Откройте `dist/index.html` через локальный HTTP-сервер, например:

```powershell
python -m http.server 8000 --directory dist
```

Затем перейдите на `http://localhost:8000`. Открытие файла напрямую (`file://`) не поддерживает ES modules.

## Публикация

Workflow `.github/workflows/pages.yml` публикует папку `dist/` на GitHub Pages при push в ветку `main`. Источник Pages в настройках репозитория — **GitHub Actions**. Для входа по email-ссылке в Firebase Authentication должен быть разрешён домен `lyaoakyn-del.github.io`.

## Структура

- `dist/` — публикуемый сайт и PWA;
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages;
- `.openai/hosting.json` — исходные настройки прежнего хостинга ChatGPT Sites.
