# Квадрат дыхания

Адаптивный статический веб-инструмент с тремя режимами дыхания: квадрат с равными фазами, длинный выдох 4/6 без задержек и циклический вздох с мягким дополнительным вдохом. Тайминг — ориентир, дыхание должно оставаться комфортным.

Выбранный режим и настройки хранятся только в браузере. Внешние библиотеки и серверная база данных не используются.

## Структура

- `dist/` — публикуемый сайт;
- `.openai/hosting.json` — идентификатор Site и конфигурация статического хостинга.
