# Квадрат дыхания

Мобильный статический веб-инструмент для дыхания по квадрату. Настройки хранятся только в браузере. Внешние библиотеки и серверная база данных не используются.

## Структура

- `dist/` — публикуемый сайт;
- `.openai/hosting.json` — идентификатор Site и конфигурация статического хостинга.
