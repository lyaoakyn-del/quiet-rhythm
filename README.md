# Квадрат дыхания

Адаптивный статический веб-инструмент с четырьмя режимами дыхания: квадрат с равными фазами, неравный квадрат 4/2/2/2 с более длинным вдохом, длинный выдох 4/6 без задержек и циклический вздох с мягким дополнительным вдохом. Бодрящий эффект неравного квадрата не доказан; тайминг — ориентир, дыхание должно оставаться комфортным.

Есть светлая и тёмная темы; в тёмной теме движущийся маркер оставляет искристый след. По завершённым практикам ведётся история с датой, временем, режимом, количеством кругов и длительностью. Необязательная оценка настроения до и после позволяет сравнивать средние значения по дням, месяцам и режимам. Историю можно удалить из приложения.

Выбранный режим, настройки, история и оценки настроения хранятся только в браузере. Внешние библиотеки и серверная база данных не используются.

## Структура

- `dist/` — публикуемый сайт;
- `.openai/hosting.json` — идентификатор Site и конфигурация статического хостинга.
